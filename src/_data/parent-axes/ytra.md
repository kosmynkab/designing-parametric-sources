## Expected behaviour

YTRA concerns vertical transparency. The intended transformation changes a
character’s height while preserving its horizontal structure, intended stroke
relationships, and recognisable construction.

> That transformation is different for different groups of characters – uppercase letters, lowercase letters (separate transformation for descender, ascender and x-height) all call for separate child axes.
